# Проект UNIVERSE DESIGN

## Общая информация
Проект представляет собой портфолио-сайт дизайн-студии "UNIVERSE DESIGN", которая специализируется на создании визуальных медиа-проектов, 3D-анимации и медиа-арте. Сайт демонстрирует творческие работы студии и предоставляет контактную информацию.

## Структура проекта

```
.
├── about.css           # Стили для страницы "О нас"
├── about.html          # Страница с информацией о студии
├── CNAME               # Файл для GitHub Pages с доменным именем
├── fonts/              # Шрифты для сайта
├── icon/               # Иконки и фавиконы
├── index.html          # Главная страница с интерактивным 3D-кубом
├── logo/               # Логотипы и изображения для соцсетей
├── projects/           # Директория с отдельными страницами проектов
├── projects.css        # Стили для галереи проектов
├── projects.html       # Страница со списком всех проектов
├── robots.txt          # Правила для поисковых и AI-краулеров + Content-Signal
├── script.js           # Основной JavaScript с логикой сайта
├── sitemap.xml         # Карта сайта (обновляется вручную при добавлении проекта)
├── style.css           # Общие стили для всего сайта
├── UNIVERSEхLedPulse/  # Медиафайлы для проекта LedPulse
└── UNIVERSEхLedPulse.html # Страница коллаборации UNIVERSE x LedPulse
```

## Ключевые проекты в портфолио
В разделе `projects/` находятся 5 основных проектов:
1. **ECHO 2.0** - медиа-визуал для объёмной LED-инсталляции
2. **INTERVALS 2023** - визуальный экспириенс для музыкального фестиваля
3. **LADA VESTA SW CROSS** - автомобильная визуализация
4. **PRE-EVENT OUTLINE 2025** - моушн-дизайн проект
5. **FINOPOLIS 2022 | T1** - дизайн-проект для финтех-мероприятия

## Технологии
- **Frontend:** Чистый HTML5, CSS3 и JavaScript без фреймворков
- **3D:** Собственная реализация интерактивного 3D-куба на Canvas API
- **Анимации:** CSS-анимации и GIF-файлы
- **Мультимедиа:** Интеграция с Vimeo и YouTube для видеоконтента
- **SEO:** Структурированные данные JSON-LD для Google и Яндекс

## Основные фичи сайта
1. **Интерактивный 3D-куб** на главной странице, который вращается при взаимодействии пользователя
2. **Адаптивный дизайн** для корректного отображения на различных устройствах
3. **Галерея проектов** с детальной информацией о каждом проекте
4. **Полноэкранный просмотр** изображений и видео
5. **Мобильная поддержка** с жестами для навигации по контенту

## Хостинг и размещение
- Сайт размещен на **GitHub Pages**
- Домен настроен через файл CNAME
- Доменное имя: universe-design.com

## SEO и доступность для AI-агентов
- `robots.txt` с явными правилами для AI-краулеров (GPTBot, ClaudeBot, PerplexityBot,
  Google-Extended и др. — все разрешены) и директивой `Content-Signal`
- `sitemap.xml` со всеми 9 страницами сайта
- `<link rel="canonical">`, `meta description`, Open Graph и Twitter Card на каждой странице
- Структурированные данные JSON-LD для улучшения видимости в поисковых системах
- Информативные alt-теги для всех изображений
- Атрибуты `loading="lazy"` для отложенной загрузки изображений

**Ограничение хостинга:** GitHub Pages не позволяет задавать свои HTTP-заголовки,
поэтому `Link`-заголовки (RFC 8288) и Markdown negotiation по `Accept: text/markdown`
на текущей конфигурации недоступны — для них потребуется прокси вроде Cloudflare.
